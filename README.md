## L'idée

On part de zéro : pas une ligne de code, juste ce fichier. Chacun vient poser sa pierre (une fonction, une correction, une ligne de doc) et le bot grandit commit après commit.

Tout le monde a sa place. Si tu viens de découvrir ce qu'est un terminal, tu es bienvenu. Si tu codes depuis vingt ans aussi : relire, conseiller, débloquer quelqu'un, ça compte autant qu'écrire du code.

Pas d'horaires, pas d'obligation. Tu contribues quand tu veux, autant que tu veux.

## Je débute : par où commencer ?

Personne ne sait tout ça au départ.

1. **Crée un compte GH** (**G**it**H**ub) si tu n'en as pas.
2. **Apprends le minimum de Git** : ***forker***, puis ***cloner*** un dépôt, créer une branche, faire un ***commit***, ouvrir une ***PR*** (**P**ull **R**equest). Le dépôt [first-contributions](https://github.com/firstcontributions/first-contributions) t'entraîne pas à pas (il existe en français).
3. **Regarde les [***issues***](https://github.com/devhub-community-staff/collabot/issues)** ou ouvre-en une pour proposer une idée. Si tu prends une tâche, écris « je prends » dessus, pour que deux personnes ne fassent pas la même chose, ou alors, en connaissance de cause, et des co-contributeurs.
4. **Bloqué ?** Pose ta question dans l'issue ou sur le [serveur Discord DevHub](https://discord.gg/9vHv5qhFVC). Aucune question n'est bête ici.

## Je sais déjà utiliser Git

- **Fork**, branche depuis `main`, pull request vers `main`.
- **Une PR = une seule chose.** Une petite PR est relue vite.
- Dans la **PR**, explique ce que tu as fait et comment tu l'as testé.
- Python avec [discord.py](https://discordpy.readthedocs.io/).
- Une grosse évolution en tête ? Ouvre d'abord une issue pour en discuter.

## Les relectures

Chaque PR est relue avant d'être fusionnée. Ce n'est pas un examen : on t'explique ce qui peut être amélioré, et pourquoi. Qu'on te demande des changements, c'est normal, ça arrive à tout le monde.

## Règles du jeu

- Bienveillance d'abord : on a tous débuté.
- Jamais de secret (token, mot de passe, clé) dans le code.
