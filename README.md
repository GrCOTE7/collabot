# CollaBot

Un bot Discord construit à plusieurs, ouvert à tous, pour apprendre à coder **et** à travailler en équipe avec Git.

> Le bot n'est pas le but. Le but, c'est d'apprendre en le construisant.

## L'idée

On part de zéro : pas une ligne de code, juste ce fichier. Chacun vient poser sa pierre (une fonction, une correction, une ligne de doc) et le bot grandit commit après commit.

Tout le monde a sa place. Si tu viens de découvrir ce qu'est un terminal, tu es bienvenu. Si tu codes depuis vingt ans aussi : relire, conseiller, débloquer quelqu'un, ça compte autant qu'écrire du code.

Pas d'horaires, pas d'obligation. Tu contribues quand tu veux, autant que tu veux.

## Je débute : par où commencer ?

Personne ne sait tout ça au départ.

1. **Crée un compte GitHub** si tu n'en as pas.
2. **Apprends le minimum de Git** : cloner un dépôt, créer une branche, faire un commit, ouvrir une pull request. Le dépôt [first-contributions](https://github.com/firstcontributions/first-contributions) t'entraîne pas à pas (il existe en français).
3. **Regarde les [issues](https://github.com/devhub-community-staff/collabot/issues)** ou ouvre-en une pour proposer une idée. Si tu prends une tâche, écris « je prends » dessus, pour que deux personnes ne fassent pas la même chose.
4. **Bloqué ?** Pose ta question dans l'issue ou sur le [serveur Discord DevHub](LIEN_INVITATION). Aucune question n'est bête ici.

## Je sais déjà utiliser Git

- Fork, branche depuis `main`, pull request vers `main`.
- **Une PR = une seule chose.** Une petite PR est relue vite.
- Dans la PR, explique ce que tu as fait et comment tu l'as testé.
- Python avec [discord.py](https://discordpy.readthedocs.io/).
- Une grosse évolution en tête ? Ouvre d'abord une issue pour en discuter.

## Les relectures

Chaque pull request est relue avant d'être fusionnée. Ce n'est pas un examen : on t'explique ce qui peut être amélioré, et pourquoi. Qu'on te demande des changements, c'est normal, ça arrive à tout le monde.

## Règles du jeu

- Bienveillance d'abord : on a tous débuté.
- Jamais de secret (token, mot de passe, clé) dans le code.
